# GameTopUp Bolivia

Tienda online de recargas de videojuegos para clientes de Bolivia. Proyecto construido con Next.js, TypeScript, Tailwind CSS y preparado para Vercel + Neon PostgreSQL.

## Estado inicial

- Base del proyecto en preparación.
- Pagos por QR boliviano y transferencia bancaria con confirmación manual del administrador.
- Integración Shop2TopUp desde el servidor; nunca exponer credenciales en el navegador.
- Notificaciones de pedidos mediante Telegram.

## Variables privadas previstas

Consulta `.env.example`. No subas credenciales reales al repositorio.

## Desarrollo

```bash
npm install
npm run dev
```
